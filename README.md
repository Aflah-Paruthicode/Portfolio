 # My Personal Portfolio

 *a sleek, animated, and modern portfolio built to showcase my software engineering journey. this project isn't just a list of links it's a reflection of my design sense and technical growth.*  
 

 ### Sections
- **Hero:** a high impact entrance using modern Css animations animations.
- **About Me:** my story, my stack, and my developing with love philosophy.
- **Featured Work:** a curated selection of my high signal projects.
- **Career Journey:** a timeline of my learning, from node.js internals to ai powered apps.
- **Contact:** a direct line to reach me for collaborations or opportunities.

### Tech Stack
- **React.js:** for a fast, single page application experience.
- **Tailwind Css:** for clean, utility first styling.
- **Email Js:** for handling the form submission.
